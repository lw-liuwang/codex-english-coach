# 学习与复习

学习融入实际任务。你可以用中文、英文或混合表达，练习不阻塞开发，也不要求每轮答题。

## 读写规则

| 场景 | Codex 如何回应 | 卡片如何回忆 |
| --- | --- | --- |
| 中英混写或值得修改的英文 | 给出自然英文，用中文解释有用的修改和词汇，继续原任务。 | 中文意图或隐藏答案的填空 → 正确英文。 |
| 主动求助英文词句 | 用中文解释当前义项及必要的句子结构，然后记录。 | 英文语境 → 中文含义与解释。 |
| 普通交流 | 使用易懂英文，不默认附翻译或词表；重要决定附简短中文说明。 | 没有学习点时不生成卡片。 |

长需求和技术文稿只处理相关段落，保留原意、条件与判断强度。写作只存修改和词汇片段，不存完整输入；阅读保留必要的一句原文。不同义项及读写方向分开记录，重复遇见不等于复习成功。

说“赶时间”或“暂停英语学习”会暂停当前聊天的教学与记录；说“恢复英语学习”继续，不补记暂停期间的内容。

## 复习

在网页查看到期卡片，先回忆、再揭晓答案，按实际感受选择：

| 自评 | 下次安排 |
| --- | --- |
| 忘了 | 回到第一级，次日再看。 |
| 费劲 | 退一级，按退后间隔安排，最低为次日。 |
| 熟悉 | 升一级，按新间隔安排，同日最多升一级。 |

间隔为 **1、3、7、14、30、60 天**，日期按 `Asia/Shanghai` 计算。新卡次日首次复习；第一次选“熟悉”后间隔为 3 天。评分后离开当天队列，重复提交不重复推进。

评分是当次自评。保存过、解释过、看过多次，都不直接表示掌握；系统也不根据中英文输入推断能力。
